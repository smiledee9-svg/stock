# SmartStock - ระบบจัดการสต็อกสินค้าออนไลน์

ระบบเว็บแอปพลิเคชันสำหรับบันทึกและจัดการสต็อกสินค้า ออกแบบให้รองรับการใช้งานบนมือถือและคอมพิวเตอร์อย่างลื่นไหล พร้อมระบบแจ้งเตือนสินค้าใกล้หมด บันทึกประวัติรับเข้า-ตัดออก และพร้อมดีพลอยขึ้น **Cloudflare Pages** ให้ออนไลน์ฟรี 24 ชม.

---

## 🌟 ฟีเจอร์หลัก
1. **จัดการสต็อกสินค้า (Inventory):**
   - เพิ่ม ลบ แก้ไข รายการสินค้า กำหนดราคา หมวดหมู่ และหน่วยนับ
   - ปุ่มลัด รับของเข้า (+IN) และ ตัดของออก (-OUT) พร้อมระบุเหตุผลได้ทันที
2. **ประวัติการเคลื่อนไหว (History Log):**
   - บันทึกทุกยอดรับเข้า/ตัดออก พร้อมวันเวลาและยอดคงเหลือแบบเรียลไทม์
   - กรองดูเฉพาะยอดรับเข้า หรือตัดออกได้
3. **ระบบแจ้งเตือนของใกล้หมด (Low Stock Alert):**
   - เตือนอัตโนมัติเมื่อจำนวนสต็อกต่ำกว่าหรือเท่ากับจุดเตือน
   - แถบสรุปด่วนและแท็บเตือนของหมด พร้อมปุ่มเติมสต็อกทันที
4. **ภาพรวมคลังสินค้า (Dashboard Metrics):**
   - สรุปรายการสินค้า, จำนวนชิ้นรวม, มูลค่าสต็อกรวม และรายการที่ใกล้หมด
5. **สำรองและกู้คืนข้อมูล (Backup & Restore):**
   - Export/Import ข้อมูลเป็นไฟล์ JSON ย้ายเครื่องได้สะดวก ข้อมูลไม่สูญหาย
6. **ธีมมืด/สว่าง (Dark / Light Mode):**
   - รองรับการสลับโหมด พร้อมถนอมสายตา

## 🚀 วิธีนำขึ้น Cloudflare Pages (ฟรี 24 ชม.)

### ขั้นตอนที่ 1: นำโค้ดขึ้น GitHub
1. เปิด [GitHub.com](https://github.com) แล้วสร้าง Repository ใหม่ (เช่น ชื่อ `stock-manager`)
2. รันคำสั่งในเทอร์มินัลโฟลเดอร์นี้:
   ```bash
   git remote add origin https://github.com/<USERNAME>/<REPO_NAME>.git
   git branch -M main
   git push -u origin main
   ```

### ขั้นตอนที่ 2: เชื่อมต่อกับ Cloudflare Pages
1. เข้าสู่ระบบ [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. ไปที่เมนู **Workers & Pages** ทางซ้ายมือ
3. กดปุ่ม **Create application** > เลือกแท็บ **Pages**
4. เลือก **Connect to Git** แล้วเลือก Repository GitHub ที่เพิ่งสร้าง
5. ตั้งค่าการ Build:
   - **Framework preset:** `None`
   - **Build command:** *(เว้นว่างไว้)*
   - **Build output directory:** `.` หรือ `/` (เนื่องจากเป็น HTML/CSS/JS ล้วน ไม่ต้องคอมไพล์)
6. กด **Save and Deploy**
7. ระบบจะประมวลผลประมาณ 30 วินาที และให้ลิงก์เว็บของคุณ (เช่น `https://stock-manager.pages.dev`) สามารถเปิดใช้งานผ่านมือถือได้ทันทีตลอด 24 ชั่วโมง!
